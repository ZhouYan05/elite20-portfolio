## 阶段 1：选题（约 20 分钟）

- Prompt 要点：「从我的 C1–C6 产出里挑两个最适合写成传播内容的选题，按 C7 的『内容从哪来』表格对照」。
- AI 给出 4 个候选（C1 翻译经验 / C5 GitHub / C6 Web App / 学习心得），我选 C6 Web App（有成品链接可带流量闭环）与 C5 GitHub（面向最大读者群的新手教程）。
- 人工决策：不选「C1 翻译」——虽然素材足，但与「用 AI 做东西」的主线偏离，账号早期需要垂直。

## 阶段 2：写作（约 50 分钟）

- Prompt 要点：「按 C7 正文结构（痛点开头→背景→过程→心得→行动号召）写两篇 1500 字左右的文章，标题用『第一人称+真实』公式；全部素材只来自我的真实经历」。
- 关键迭代：
  1. AI 初稿标题「零代码开发 AI 产品全攻略」偏教程腔 → 改为「不会写代码的我，用 AI 做了一个 Web App 上线了」（第一人称+真实）；
  2. 文章 1 的「三个坑」全部来自真实踩坑记录（headless 空白截图、pollinations 限频、拒绝引入框架），AI 不得虚构；
  3. 文章 2 的 Windows symlink 坑来自我在 C5A 的真实体验，作为「读懂仓库」部分的差异化素材；
  4. 两篇文章末尾都加行动号召（体验链接/仓库链接），让内容带动 C6/C5 的公开作品。
- 排版：输出为公众号可直接粘贴的 HTML（正文 16px、行距 1.9、小标题用色块区分），符合 C7 排版建议。
