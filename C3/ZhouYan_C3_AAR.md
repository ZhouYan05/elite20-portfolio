# ZhouYan_C3_AAR：C3 群内参与复盘（七维 AAR）

## S 情境（Situation）

C3 要求「在课程群内持续做高质量参与」：提出好问题、给出有证据的反思、推动讨论向前。此前我在群里的习惯是**潜水 + 默默交作业**——群里讨论基本只看不发，怕「说错丢人」。

## T 任务（Task）

至少 3 次有「推动」性质的参与（非 +1/表情），其中至少 1 次提问具备完整要素（上下文/已尝试/具体卡点），并总结自己的提问 checklist。

## A 行动（Action）

1. 把 C6A 的提交数据仪表盘分享到群里（用数据视图终结「谁交了没」的散乱讨论）；
2. 把 C6 Web App 链接发群并邀请试用（按 C6 要求，附限制说明）；
3. 把 C10H 的 WSL2 安装卡点整理成完整要素提问发出（附已尝试路径与排除项）；
4. 三条参与全部落档反思文件，并总结提问 checklist。

## R 结果（Result）

- 3 条参与记录成形：1 条数据证据型、1 条工具分享型、1 条完整要素提问型；
- 提问 checklist（5 条）写入反思文件，成为我后续所有技术提问的模板；
- 反思文件与 AI 日志、AAR 齐全（artifactCompleteness ✅）。

## ΔR 偏差（Deviation）

- **R̂：预期「现场即兴参与」→ R：实际「先产出再分享」。** 我发现我的参与方式天然是「带成果进群」（仪表盘、App），而不是即时讨论——即兴发言对我来说质量不稳定，带产出进群更真实也更有推动力。这是可接受的偏差，但意味着「参与频率」需要刻意安排。
- **R̂：预期 3 条全部有回应 → R：回应情况待确认。** 消息发出后同学回应需要时间，闭环证据（collaboration 维度）暂缺，需在提交前补记。

## 失败分析

- 失败点：此前长期潜水——归因：把「说错丢人」的顾虑放在「讨论价值」前面，且没有「带产出进群」的意识。对策：把「每周至少一次带产出的群内分享」写进 C10 智能体的每周循环（L2 经验）。
- 失败点：提问习惯差——旧习惯是「这个怎么做」式提问。对策：checklist 第 4 条「先自查再提问」已经在本周 C10H 提问中实际执行（查文档 + 3 条路径试错后才问）。

## 下周计划

1. 为 3 条参与记录补记回应与闭环（谁回应了、结论是什么）；
2. 下周至少 1 次「回应别人的提问」型参与（帮助他人，补 collaboration 短板）；
3. 若 C10H 的 WSL2 问题群内有人给出解法，把解法回贴并归档到 C10H 安装记录。
