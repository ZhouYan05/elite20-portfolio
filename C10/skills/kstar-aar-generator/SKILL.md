# KSTAR AAR 生成器

输入：预期产出 R̂、实际产出 R、失败/卡点（各 1–3 句即可）。
输出：KSTAR 完整结构 Markdown（S/T/A/R/ΔR/失败分析/下周计划）。

## 步骤

1. 收集素材：本周目标（R̂）、实际做了什么/拿到什么（R）、卡在哪（失败点）；
2. 用表单/提示词生成 KSTAR 骨架（在线版：https://ZhouYan05.github.io/elite20-aar-writer/）；
3. 人工审校：AAR 的核心是真实——工具只搭结构，内容必须逐句核对为真实发生的事；
4. 导出 Markdown 提交。

## 迭代记录（CHANGELOG）

- v1（2026-10 下旬）：纯提示词版，直接在对话里贴 KSTAR 模板，每次都要手动排版。
- v2（2026-11-10）：固化为 elite20-aar-writer Web App——KSTAR 结构写进系统指令，表单字段与课程提交格式一一对应；增加复制/下载。改进动机：v1 格式经常跑偏（漏 ΔR、下周计划写成流水账），把结构交给程序后不再出错。

## 约束

- 不编造内容：R̂ 与 R 不一致时必须如实写 ΔR，禁止「事后把 R̂ 改成 R」；
- 失败分析至少 1 条真实卡点，无卡点时写「本周无重大失败」并说明原因。
