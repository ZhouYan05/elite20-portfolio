# ZhouYan_C10H_配置说明：Hermes Agent 配置方案（拿来主义 + 个性化）

> 说明：本机 WSL2 因权限受限无法启用（见安装记录）。本文件是**已就绪的配置方案**——在任一具备管理员权限的 Windows/Linux 环境可直接照此执行。

## 一、拿来主义：拿了什么

| 拿了什么 | 说明 |
|---|---|
| Hermes Agent 平台本体（MIT 协议，36k+ stars） | 自我进化 AI Agent 平台：技能系统、记忆、自我进化循环——整个平台直接复用，不自研 |
| 官方安装脚本 | 环境检查（Python 3.11+ / Node.js）与依赖安装逻辑，不改写 |
| 官方默认配置结构 | Agent 的角色、工具、记忆的默认组织方式 |

## 二、怎么配置的（我的选择）

### 环境层

| 项 | 我的选择 | 理由 |
|---|---|---|
| 运行方式 | WSL2（Ubuntu 默认发行版） | 官方支持路径，与 Windows 主机文件互通（可读写 C10 技能库） |
| Python | 3.13.5（WSL 内安装） | 满足 3.11+，与课程其他脚本同版本便于互迁 |
| Node.js | 系统包管理器安装 | 安装脚本会处理，不手动干预 |

### 配置层（安装后按此顺序配置）

1. **首次对话目标**：按 Level 1 要求，不聊「hello」——首个任务定为「读取 `/mnt/d/.cogseed/userWorkSpace/完成剩余挑战任务/C10/ZhouYan_C10_skills/` 下的技能库，生成一份技能使用周报」；
2. **技能迁移**：把 C10 技能库的 6 个技能导入 Hermes（格式从我的 SKILL.md 迁移到 Hermes 技能格式，保留 frontmatter 与使用记录）——这是「用它加速 C8/C9/C10」的具体动作；
3. **记忆接入**：把 L2_experiences/ 的 AAR 作为 Hermes 的初始记忆注入，验证「跨 agent 经验迁移」是否成立；
4. **自我进化验证**：按 Hermes 的自我进化循环跑一周，对比「Hermes 管理的技能」与「我手工管理的技能」的迭代速度。

## 三、在哪里做个性化修改

| 修改点 | 内容 |
|---|---|
| 技能格式适配器 | 写一个 SKILL.md → Hermes 技能格式的转换脚本（我的技能含 USAGE.md 使用记录，Hermes 默认无此字段） |
| 周报模板 | 把 C6A 的 weekly_summary 模板接到 Hermes 的周报输出上 |
| 中文语境 | 默认 persona 增加「中文优先、课程术语（KSTAR/R̂/ΔR）不翻译」约束 |
