# C3C 联合成果 — 可交接的 KSTAR AAR 生成技能包

> 协作：周岩（封装） × 宋君毅（试用）｜成果目录：`C3C/migration_package/`｜日期：2026-11-16

## 1. 成果是什么（一句话）

一套**别人拿到就能独立跑通**的 `kstar-aar-generator` 技能包：技能本体 + 交接说明 + 试用任务单 + 迁移自检清单 + 回执模板。目标不是"把我的文件发过去"，而是"把我的能力变成他也能用的能力"。

## 2. 为什么这算"联合成果"，而不是文件拷贝

| 维度 | 单纯拷贝 | 本次成果 |
| --- | --- | --- |
| 接收方 | 拿到 SKILL.md，但仍要问我怎么用 | 拿到 4 份文档，按任务单可直接开工 |
| 验收 | 无标准，靠感觉 | 5 条可观察验收标准，逐条可判定 |
| 失败处理 | 卡住就回退到"找人问" | 交接说明列出 3 类常见失败与自救路径 |
| 反馈闭环 | 没有 | 回执模板固定了卡点描述格式，回流可迭代技能 |
| 责任 | 无主 | A 侧封装、B 侧试用，各自有明确交付物 |

联合的部分在于：**产物的价值由接收方是否跑通决定**，而不是由我这侧写得多完整决定。A 侧只完成了自己那半，另半在 B 侧手上。

## 4. 可观察验收标准

1. 接收方**不询问封装方**即可完成一次完整 AAR 生成；
2. 产出的 AAR 含 S/T/A/R/ΔR/失败分析/下周计划六段，无缺段；
3. ΔR 与真实偏差一致，未出现"把 R̂ 改成 R"的事后修饰；
4. 至少 1 条真实失败点，或明确写"本周无重大失败"并给出原因；
5. 卡点以"现象→我试了什么→卡在哪"三段式记录，可直接用于迭代技能。

## 5. 复用范围

- C3 群内参与复盘、C8/C9 周度 AAR：直接套用同一结构，省掉每次重排格式；
- 交接给同伴：换人接手时不需要口头教学，文档即教学；
- 技能迭代：回执里的卡点可直接转成 CHANGELOG 条目。
