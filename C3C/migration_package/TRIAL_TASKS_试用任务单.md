# 试用任务单 — 一次完整 AAR 生成

> 给宋君毅：照下面 5 步做一次，就是一次合格的技能迁移试用。全程不需要问封装方。

## 第 1 步：选题（5 分钟）

从你本周真实做过的一件事里选一个，建议优先选**做得不顺的**——顺的任务写不出 ΔR。写下两句：
- 我以为会拿到什么（R̂，写具体，别写"做好"）；
- 实际拿到什么（R，写你手里真实有的东西）。

## 第 2 步：记卡点（5 分钟）

按三段式写 1–3 条：
```
现象：
我试了什么：
卡在哪：
```
禁止写"有点难""不太顺利"这类无法核对的描述。

## 第 3 步：生成结构（10 分钟）

按 `skill/kstar-aar-generator/SKILL.md` 的步骤生成六段 AAR：
S 情境 → T 任务 → A 行动 → R 结果 → ΔR 偏差 → 失败分析 → 下周计划。

## 第 4 步：人工审校（10 分钟）

逐句核对，重点三问：
1. 这句话是真实发生的，还是我为了好看补的？
2. ΔR 写的是真实偏差，还是我把 R̂ 改成了 R 之后"没有偏差"？
3. 下周计划每一条，能不能对应到某条失败点或偏差？

## 第 5 步：导出与回执（5 分钟）

- 导出 Markdown，命名 `姓名_AAR_主题.md`；
- 回填 `RECEIPT_回执模板.md`，交回封装方。

## 验收（5 条，逐条回答是/否）

| # | 标准 | 是/否 |
| --- | --- | --- |
| 1 | 未询问封装方即完成全流程 | |

| 4 | 至少 1 条真实失败点（或明确说明本周无重大失败及原因） | |
